# Profile motion

An eight-second silent loop for the profile, built in Remotion with the Cinetic film workflow. The coastal illustration, palette and typography come from the personal website. The water uses independent, frame-driven displacement and the gull is drawn with moving wings. The optional SnapCN Text Reveal component remains available in `src/vendor/snapcn` for future variants; the current banner contains no subtitle.

The sources, brief and treatment are included so the banner can be edited. From this directory, run `npm install`, `npm run check`, and `npm run studio` to edit, or `npm run render` to produce an MP4. Remotion may prompt to download a compatible browser. The GitHub profile uses a 25 fps GIF because GitHub READMEs do not play embedded MP4s.

Cinetic and SnapCN are MIT licensed; typefaces use the SIL Open Font License. The license texts are in `licenses/`. The coastline is an original generated illustration commissioned for the portfolio and does not depict a verified real-world location.
